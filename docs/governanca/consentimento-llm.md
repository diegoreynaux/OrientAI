# Termo de Consentimento para Uso de LLMs

## 1. Finalidade do Tratamento
O OrientAI utiliza inteligência artificial para auxiliar na transcrição de reuniões, análise estrutural de textos acadêmicos e triagem bibliográfica.

## 2. Provedores Externos
Ao utilizar funcionalidades de nuvem, fragmentos de textos poderão ser enviados para provedores (ex: OpenAI, Anthropic). 
Nenhum provedor configurado no sistema está autorizado a utilizar seus dados para treinamento de novos modelos, conforme contratos Enterprise vigentes.

## 3. Uso Local (Privacy-First)
Para pesquisas de natureza sigilosa (ex: patentes não depositadas), encorajamos a ativação do modo local (Ollama). Neste modo, os dados não saem do servidor da sua instituição.

## 4. Retenção
Gravações de reuniões são deletadas imediatamente após a transcrição. Históricos de prompts e respostas são guardados para fins de auditoria acadêmica.

*Eu confirmo ter lido e aceito as condições de uso.*
