# Checklist de Avaliação e Homologação de Provedores de IA

Este documento é utilizado semestralmente para auditar provedores externos.

- [ ] **1. Privacidade de Dados:** O contrato estipula claramente que os dados da API NÃO são usados para treinamento de modelos fundacionais?
- [ ] **2. Retenção:** O provedor obedece ao requisito de zero-retention (retenção de 0 dias) dos dados enviados para processamento?
- [ ] **3. Soberania de Dados:** Os servidores estão alocados no Brasil ou em país com legislação de proteção de dados adequada (GDPR)?
- [ ] **4. Custos e Limites:** Os *rate limits* e o modelo de *pricing* comportam a escala da instituição?
- [ ] **5. Confiabilidade e Tempo de Resposta:** O SLA do provedor (mínimo 99.9%) atende aos nossos requisitos de disponibilidade?
